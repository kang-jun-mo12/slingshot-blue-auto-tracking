# 고무줄 총 자동화 시스템 개발 보고서

작성 기준: 2026년 10월 25일.

본 과제는 카메라로 표적을 찾아 방향을 정렬하고, 거리별 상하 보정 후 고무줄을 발사하는 시스템을 개발하는 것이다. 최종 시스템은 **YOLO 검출 모델, 중심 정렬 모듈(CAM), 거리 기반 상하 보정 모듈(DPCM)**로 구성했다.

## 하드웨어 구성과 카메라 배치

라즈베리파이 카메라를 전방 막대 바로 아래에 고정하고, 막대와 같은 방향을 바라보도록 정렬했다. 좌우·상하 서보가 방향을 바꾸면 카메라도 함께 움직이므로 영상 중심을 기구의 방향 정렬 기준으로 사용할 수 있다. 장치는 목재 프레임, 방향 조절 서보, 발사 서보로 구성된다.

![막대 아래에 전방을 향한 카메라를 장착한 하드웨어 구성](architecture_images/00_hardware_configuration.png)

## 1. Task 구현을 위해 논의했던 방법들

### 1.1. 방법 1 Transformer 기반 E2E 각도 예측

이미지를 패치로 나눠 Transformer로 처리한 뒤, 회귀 출력층에서 좌우·상하 서보 목표 각도를 직접 예측하는 방식이다. 이미지와 정답 각도의 쌍으로 표적 인식부터 각도 결정까지 한 모델이 학습한다.

```text
이미지 → Transformer → 서보 목표 각도
```

### 1.2. 방법 2 YOLO 검출과 마스킹 후 CNN 각도 예측

YOLO로 표적의 박스를 검출하고 배경을 마스킹한 이미지를 CNN에 입력해 서보 각도를 예측하는 방식이다. 각도 결정에 필요한 표적의 위치와 크기는 전처리 과정에서 유지한다.

```text
이미지 → YOLO → 배경 마스킹 → CNN 회귀 → 서보 목표 각도
```

### 1.3. 방법 3 YOLO와 CAM 및 DPCM의 모듈 결합

표적 검출, 중심 정렬, 거리별 상하 보정을 분리하는 방식이다. 영상에서 각도를 직접 예측하는 대신, 검출한 좌표와 크기를 각각 CAM과 DPCM에 전달한다. 세부 구성은 5절에 설명한다.

```text
이미지 → YOLO → CAM 중심 정렬 → DPCM 거리 보정·발사 연동
```

## 2. 논의한 방법들 중 시도했던 방법들

세 방법을 모두 실제 장치에 적용해 비교했다. 각 방법의 성공 여부와 실패 시 고무줄과 표적 사이의 거리를 기록했으며, 실험 조건과 결과는 4절에 정리했다.

## 3. 시도했던 각 방법들을 선택한 이유

### 3.1. 방법 1을 시도한 이유

중간 처리 단계를 줄이고 전체 이미지의 정보를 이용해 필요한 서보 각도를 한 번에 예측할 수 있을 것으로 기대했다.

### 3.2. 방법 2를 시도한 이유

YOLO로 표적을 명확히 선택하고 배경을 제거하면, CNN이 표적에 집중해 각도를 학습할 수 있을 것으로 기대했다.

### 3.3. 방법 3을 시도한 이유

첫째, 모듈별 입력과 출력이 명확해 오류가 발생한 단계를 분석하기 쉽다.

둘째, 모든 이미지 상황의 정답 각도를 수집하는 대신 픽셀–각도 응답과 거리별 보정 관계를 나눠 학습해 데이터 확보 부담을 줄일 수 있다.

셋째, 이동 전후의 관측 피드백으로 실제 기구 응답과 예측의 차이를 보완할 수 있다.

넷째, 중심 정렬과 거리 보정을 별도로 조정할 수 있어 각 기능을 개선하기 쉽다.

## 4. 시도했던 각 방법들의 실험 결과

### 4.1. 실험 조건

장치에서 1.5~2.0m 범위에 표적 두 개를 배치하고, 방법별로 15회씩 실험했다. 성공률과 함께 실패한 시도에서 고무줄과 표적 사이의 평균 거리를 비교했다.

### 4.2. 실험 전 예상

- **방법 1:** 위치·거리·외부 조건마다 정답 서보 각도가 필요하지만 모든 상황의 데이터를 확보하기 어려워 예측 오차가 발생할 것으로 보았다. 같은 서보 각도에서도 외부 요인에 따라 고무줄 도달 거리가 달라질 수 있다는 점을 고려했다.
- **방법 2:** 마스킹으로 배경 영향을 줄일 수 있으나, 상황별 정답 각도 데이터가 필요한 문제는 남으므로 방법 3보다 오차가 클 것으로 예상했다.
- **방법 3:** 중심 정렬과 상하 보정을 분리하면 필요한 데이터와 모델 규모를 줄이면서 일관된 각도 보정을 수행할 수 있어, 세 방법 중 가장 강건할 것으로 예상했다.

### 4.3. 실제 결과와 최종 선택

| 방법 | 성공 횟수 및 성공률 | 실패 시 평균 거리 |
|---|---|---|
| 1. Transformer E2E | 4/15회, 약 26.7% | 약 11cm |
| 2. YOLO·마스킹·CNN | 5/15회, 약 33.3% | 약 13cm |
| 3. YOLO·CAM·DPCM | 10/15회, 약 66.7% | 약 4.7cm |

방법 3은 예상대로 성공률이 가장 높았고, 실패 시에도 고무줄이 표적에 가장 가깝게 도달했다. 두 평가 항목에서 모두 우수한 결과를 보여 최종 방식으로 선택했다.

## 5. 최종 적용한 모델 설명

### 5.1. 전체 아키텍처와 입출력

![YOLO와 CAM 및 DPCM으로 구성한 전체 시스템](architecture_images/01_system_architecture.png)

그림 2. 최종 시스템의 세 모듈과 입출력

| 구성 | 입력 | 출력 및 역할 |
|---|---|---|
| YOLO26l-OBB | 카메라 이미지 | 표적 중심점과 박스 크기 |
| CAM | 표적 중심점, 화면 중심점, 현재 서보 자세 | 중심 정렬을 위한 좌우·상하 각도 |
| DPCM | 박스 크기, 기준 서보 각도 | 보정된 상하 각도와 발사 서보 목표각 |

### 5.2. 모델 1 YOLO26l-OBB: 표적의 위치와 크기를 검출하는 모델

1920×1080 이미지에서 파랑 enemy 표적과 분홍 ally 표적을 구분하며, 자동추적은 파랑 표적을 대상으로 한다. **특징 추출부 → 다중 해상도 특징 융합부 → OBB 검출 헤드**를 거쳐 클래스와 회전 박스를 예측한다.

![YOLO26l-OBB의 상세 구조](architecture_images/02_yolo_module.png)

그림 3. YOLO26l-OBB 검출 모듈

특징 추출에는 Conv·C3k2·SPPF·C2PSA를 사용하고, 서로 다른 해상도의 특징을 융합해 검출한다. OBB의 네 꼭짓점 평균을 중심점으로, 수평 외접 박스의 폭·높이를 크기 입력으로 전달한다.

### 5.3. 모델 2 중심 정렬 모듈(CAM): 화면 중심점과 표적 중심점을 맞추는 모델

CAM(Center Alignment Module)은 **15개 다항 특징과 강건 회귀**로 서보 각도 변화에 따른 픽셀 이동 관계를 추정한다. 강건 회귀는 큰 잔차를 보이는 관측의 영향을 줄이는 방식이며, 이동 전후의 피드백으로 축별 응답을 보완한다.

![다항 회귀와 관측 피드백으로 구성한 CAM](architecture_images/03_centering_module.png)

그림 4. 실측 회귀와 관측 피드백을 결합한 CAM

화면 중심 (960, 540)과 표적 중심의 차이를 구하고, 보완된 이동 관계를 역으로 계산해 목표 서보 각도를 정한다. 이를 통해 실제 기구 응답을 반영하며 중심 오차를 줄인다.

### 5.4. 모델 3 거리 기반 상하 보정 모듈(DPCM): 거리별 상하 보정과 발사 동작을 연결하는 모듈

DPCM(Distance-based Pitch Correction Module)은 **박스 크기에서 거리를 예측하는 GP와, 거리에서 상하 보정량을 예측하는 GP**를 직렬로 연결한다. 박스의 폭·높이로 크기 지표를 구하고 그 역수를 정규화해 첫 번째 GP에 입력한다.

가우시안 프로세스(Gaussian Process, GP) 회귀는 커널로 입력 간 관계를 표현하고 학습 데이터에서 연속적인 출력값을 추정하는 방법이다. 두 회귀기는 Matérn ν=1.5 커널을 사용하며, 각각의 예측 평균을 거리와 상하 보정량으로 사용한다.

![GP 예측과 동작각 출력을 통합한 DPCM](architecture_images/04_pitch_module.png)

그림 5. 거리·상하 보정량 예측과 발사 연동을 수행하는 DPCM

예측한 보정량을 CAM의 기준 각도에 반영하고, 보정된 상하 서보 각도와 발사 서보 목표각을 출력한다. 거리 보정과 발사 동작을 하나의 모듈로 연결한 구성이다.

### 5.5. 최종 실행 순서

1. 라즈베리파이 카메라가 영상을 촬영해 PC로 전송한다.
2. YOLO가 파랑 표적의 중심점과 박스 크기를 검출한다.
3. CAM이 좌우·상하 서보 각도를 계산해 표적을 화면 중앙에 정렬한다.
4. 정렬된 자세를 상하 보정의 기준 각도로 정한다.
5. DPCM이 거리와 상하 보정량을 GP 회귀로 예측한다.
6. 보정량을 기준 각도에 적용하고 발사 서보 목표각을 출력한다. 발사 서보는 초기 0°에서 180°로 이동해 고무줄을 발사한다.
